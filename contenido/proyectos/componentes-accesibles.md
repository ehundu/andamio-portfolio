Una colección pequeña de componentes de interfaz pensada desde el principio para que se puedan usar sin ratón y con un lector de pantalla.

## Lo que incluye

- Botones, enlaces y campos de formulario, con el foco siempre visible.
- Un desplegable y un interruptor, sin más JavaScript del necesario.
- Una página de pruebas para repasar todo con el teclado.

## Por qué

Casi toda la accesibilidad se gana en el HTML. Los componentes están escritos con las etiquetas que ya existen para cada cosa, y solo llevan atributos extra donde de verdad hacen falta.
